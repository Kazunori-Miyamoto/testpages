GitHub Pages で公開する制作物置き場。

## 公開中
- 声かけの記憶テスト（最新版）：https://kazunori-miyamoto.github.io/testpages/koekake/

## フォルダ構成

```
/
├── index.html                         … トップ（プロジェクト一覧）
├── .nojekyll                          … Jekyll処理を無効化（静的HTMLをそのまま配信）
├── koekake/                           … 声かけの記憶テスト（本番・短いURL）
│   ├── index.html
│   ├── ogp.png                        … SNS共有時のプレビュー画像
│   └── qr.png                         … イベント・チラシ用QRコード
└── projects/
    └── 名古屋市学生社会課題解決プロジェクト/
        ├── index.html                 … プロジェクト内の制作物一覧
        ├── koekake-memory-test/       … v1（記憶と声かけのテスト）
        └── koekake-v2-test/           … 旧テストURL（koekake/ へ転送）
```
